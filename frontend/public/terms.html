10. Image conversion and compression limitations

Decoding, resizing and re-encoding can change compression, sharpness, colours, orientation, profiles, metadata and transparency. JPEG requires transparency to be flattened against a background; browser-local tools and explicit server options may handle that differently. A best-effort target size is not an assurance that a particular byte count will be achieved. Some browsers do not support all codecs equally, and server codec support depends on installed libraries.

A conversion labelled lossless refers to a particular encoding or operation, not preservation of every original container property. Animated inputs are currently rejected rather than promising all-frame preservation. Review the output at its intended size, confirm transparency and colours, and retain the source if future editing matters. Image background removal has additional limitations described below.

13. PDFs and document conversions

PDF operations include supported merge, extraction, split, reorder, deletion, rasterisation, image-to-PDF, metadata and structural optimisation workflows. Reordering requires a valid explicit order, and deleting all pages is rejected. Rasterisation creates images rather than editable text. Structural optimisation does not promise visual compression, image downsampling or a smaller file. A rewrite may affect bookmarks, forms, annotations, signatures or other document-level features.

Office and text conversion can change pagination, typography, embedded objects, links and layout. Fonts or legacy-format interpretation may differ from the application that created the file. Digital signatures and evidential properties may no longer be valid after rewriting. Konvertira does not certify authenticity, validate official records or preserve every interactive PDF feature. Encrypted PDFs are rejected by the current processors; no password-removal service is provided.

14. Spreadsheets and presentations

Spreadsheet conversion may alter formulas, calculated values, date formats, number formats, hidden information, charts, macros and external links. CSV represents a table, not a complete workbook; multiple sheets can become a ZIP of generated CSV files. Formula text may be retained as text and escaped to reduce formula-injection risk. This is not a guarantee that arbitrary spreadsheet content is safe to open or numerically reliable.

Presentation conversion may omit animations, transitions, speaker information, fonts or embedded media, and PDF output is not an editable presentation. Macros are not deliberately executed as a feature, but file conversion is not a comprehensive active-content sanitisation process. Validate financial totals, formulas, slide order and rendering in the intended application. Unsupported conversions are rejected rather than inferred from a general format name.

15. Metadata inspection and removal

Metadata tools inspect or remove fields that the current implementation recognises in supported formats. Pixel-based image re-encoding does not intentionally copy original metadata. PDF and Office tools cover specified properties, not every embedded object, comment, revision, hidden sheet, macro or identifier. An inspection showing no fields does not establish that a file contains no personal data or forensic information.

Metadata removal is not redaction, anonymisation, watermark removal, encryption or irreversible deletion of the original. Visible names, faces, text, screenshots and contextual information can still identify people. Other copies may retain original metadata. Review the cleaned file and its content before sharing, and use a specialised redaction or privacy workflow when required. Konvertira does not issue a privacy-compliance certificate for an output.

16. Automated background removal

Background removal uses the U²-NetP model through CPU-based ONNX Runtime on Konvertira's server, not an external AI-inference API. It produces a PNG or WebP with transparency using automated foreground segmentation. The small general-purpose model may remove wanted content or retain unwanted background. Hair, fur, glass, shadows, translucent objects and similar foreground/background colours are particularly difficult.

Review edges, orientation and alpha transparency before using the result. The operation does not identify or verify people, conceal every sensitive detail or produce a guaranteed professional-quality cut-out. Konvertira does not train the bundled model on submitted files. The model's third-party provenance and implementation safeguards are described on the Security & Data Handling page.
